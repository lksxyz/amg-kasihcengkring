# KasihCengkring

> Built with Arc Studio — money-powered apps in minutes

Non-custodial creator donation platform on Arc. Supporters send USDC directly to a
creator's payout address. The contract never holds funds and donors need no account; a
platform fee (flat + proportional) is forwarded to the treasury in the same transaction.

---

## Contract Deployments

**No Arc Testnet deployment yet.** Set `VITE_KASIH_ADDRESS` after deploying; until then the
UI treats the app as not deployed and `bun run dev:local` runs the full flow locally.

- **USDC (Arc Testnet):** `0x3600000000000000000000000000000000000000` (6 decimals)
- **maxDonation:** 500 USDC (`500000000`)
- **MIN_DONATION_FLOOR:** 0.50 USDC (`500000`)
- **Platform fee:** 0.01 USDC flat + 100 bps (1%), hard-capped at 0.05 USDC + 500 bps
- **Constructor:** `(usdc, maxDonation, treasury, feeBps, flatFee, owner)`

## What This App Does

- Creators claim a username and set a payout address + per-creator minimum. The owner sets
  a global `maxDonation`; the contract caps donations between
  `min(creator.min, maxDonation)` and `maxDonation`.
- Donors approve USDC for the exact gross amount, then call `donate()`. Two transfers in one
  transaction: net → payout address, fee → treasury (`safeTransferFrom`); the contract's
  USDC balance stays zero. Donors never pay more than they type.
- `/:username` is a public profile + donation form. `/app` is the creator dashboard
  (register, stats), `/app/history` the donation history, `/app/setting` payout/min settings.
- `/overlay` and `/overlay/:username` stream confirmed donations as animated cards for OBS;
  they subscribe to `DonationReceived` over WebSocket (polling as fallback) and need no
  wallet or backend.
- An optional Supabase mirror supplies profiles and donation history; without it the app
  still works from chain reads alone.
- Pausing blocks registration/donations but never `updatePayoutAddress`, so creators can
  always redirect funds.

## Tech Stack

- Frontend: React 18, Vite 6, TypeScript, Tailwind CSS, React Router, Sonner
- Web3: wagmi v2, viem v2, ConnectKit
- Contracts: Solidity 0.8.28 + Foundry + OpenZeppelin 5.1. Sources in `contracts/`, tests in
  `contracts/test/*.t.sol`. Build `bun run contracts:build`, test `bun run contracts:test`.
- Wallet: injected (MetaMask, etc.); chain Arc Testnet (ID `5042002`); token USDC (6 decimals)
- Hosting: static SPA on **Netlify** (`netlify.toml`); no backend, no server-held keys
- Deploy: `bun run build` → `dist/`, or `bun run deploy` (Netlify CLI)

## To Run

```bash
bun install
bun run dev        # http://localhost:5173
bun run dev:local  # local Arc node + deploy + funded wallet + frontend
bun run check      # lint + typecheck
bun run build      # production bundle
```

`dev:local` requires the foundry-arc fork (`arc-anvil`). It writes `.env.localdev` and runs
Vite with `--mode localdev`, so plain `bun run dev` still targets Arc Testnet.

No environment variables are required for local development; `.env.example` documents the
optional ones.
